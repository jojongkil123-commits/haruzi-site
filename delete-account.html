스킨해루질의 버디 찾기 계정과 관련 데이터를 삭제하는 방법을 안내합니다. 버디 찾기를 쓰지 않았다면 서버에 계정이 없으며, 모든 기록(포인트·출조·조과)은 휴대폰 안에 저장되므로 앱을 삭제하면 함께 지워집니다(iPhone 포인트의 iCloud 동기화는 아래 참고).

앱 안에서 바로 삭제 (권장)

  1. 앱 실행 → 버디 찾기 메뉴
  2. 오른쪽 위 사람 아이콘(내 프로필)
  3. 아래로 스크롤 → 계정 삭제
  4. 확인 창에서 계정 영구 삭제

삭제는 즉시 처리되며 되돌릴 수 없습니다.

계정을 유지하면서 일부 데이터만 삭제

  • 모집글: 앱에서 직접 삭제할 수 있습니다.
  • 쪽지: 한 통씩 지우는 기능은 없습니다. 계정을 삭제하면 함께 지워지며, 특정 쪽지 삭제가 필요하면 이메일로 요청해 주세요.
  • 프로필 사진·소개: 내 프로필에서 비우고 저장하면 됩니다.
  • 휴대폰에 있는 기록(포인트·출조·조과·사진): 앱 안에서 개별 삭제하거나 앱을 삭제하면 지워집니다. 단, iPhone 포인트가 iCloud로 동기화돼 있다면 앱 안에서 지워야 iCloud에서도 지워집니다.
